# 画面のブロック番号と届書の対応

入力画面のブロックに出ている紫のラベル（`2.6.1` 等）が、届書のどの位置に
当たるかの一覧。**この番号は公式のものではなく、画面と届書を突き合わせる**
**ためにこのアプリが振っているもの**で、届書には印字されない。

## 番号の振り方

- 公式XSD（`iykckn_all_v3_0_0`）のツリーをそのまま辿り、**入れ物の要素にだけ**
  上から順に番号を振る（`xsdLabels.ts`）。値だけの欄には番号がつかない。
- 番号は**届書の並び順**で、画面の並び順ではない。画面はタブに分かれているので、
  1つのタブの中では番号が飛ぶ（例：基本情報タブには 2.9 / 2.11 / 2.12 が出るが、
  2.1〜2.8 は治験計画概要タブと治験使用薬タブにある）。
- 「繰り返し」は届書がその枠を繰り返せることを示す（XSD の `maxOccurs="unbounded"`）。

- ブロック数: **61**
- 生成: `npm run blockmap`（このファイルと `届書PDF_ブロック番号つき.pdf` を作る）
