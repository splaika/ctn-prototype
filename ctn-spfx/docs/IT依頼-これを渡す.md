## 1.5.0.0 に入っている修正（参考）

デプロイ済みの `1.0.0.0` から、以下が入っています。実テナントで踏んだ不具合が中心です。

**書き込みができなかった原因の修正（最重要）**

SPFx の `SPHttpClient` は OData v4 を使うため、etag は応答の `@odata.etag`
（アットマーク付き）に載ります。実装が `odata.etag`（@ なし）を読んでいたため
etag が常に未取得となり、`IF-MATCH` を使う**すべての更新が失敗**していました。
保存・届の作成・承認が動かなかったのはこれが単一の原因です。

**その他の修正**

- 失敗が画面に出ず「押しても無反応」に見えていた問題（保存・作成・レビュー送付・
  取り込み・XML生成に例外処理が無かった）
- 読み込み失敗時に「読み込み中…」のまま固まる問題
- 1行テキスト列の 255 文字超過で書き込みが失敗する問題
- 作成の2段目が失敗すると中途半端な届が残り、再試行のたびに増える問題
- 壊れたデータが1件あると全画面が開けなくなる問題
- 監査ログの追記失敗が業務操作を失敗扱いにする問題

**UI 改善**

- 操作バー（保存・レビュー送付など）を画面下部に固定
- 「施設を追加」で追加されたカードへ自動スクロール
- 全幅列セクションへの配置に対応（`supportsFullBleed`）

**機能追加**

- 初期セットアップ画面（ボタン1つでリストとロール用グループを作成。
  これにより PowerShell や Entra ID アプリ登録の依頼が不要になりました）
- データソース切替の即時反映

**性能**

保存1回あたりの SharePoint への往復を 7 回から 3 回へ削減
（etag の引き継ぎ、治験成分記号のキャッシュ、採番不要時のシリーズ取得の省略、
更新後の再取得の省略）。

**検証**: テスト 138 件パス、`gulp bundle` / `package` がエラー0・警告0
